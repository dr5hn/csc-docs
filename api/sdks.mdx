## Official Packages

The Country State City ecosystem provides live REST API clients for TypeScript and Python, plus offline data packages for JavaScript/TypeScript and Python. Use a live client when you need managed, current data, server-side search, or plan-aware errors. Use an offline package when your application must run without an API key or network access.

## In the Meantime

For languages without an official SDK, you can integrate with our API using:

<Steps>
  <Step title="Direct HTTP Requests">
    Use your favorite HTTP client library to make requests directly to our API endpoints. Check our [API Reference](/api/introduction) for detailed endpoint documentation.
  </Step>
  
  <Step title="OpenAPI Generator">
    Generate a client library in your preferred language using our [OpenAPI specification](https://github.com/OpenAPITools/openapi-generator).
  </Step>
  
  <Step title="Community Libraries">
    Check our [GitHub](https://github.com) for community-contributed libraries and examples.
  </Step>
</Steps>
