## Country dropdown

Select Countries with `name`, `iso2` and `currency`, choose JSON, and download. Then read it:

```js
import { readFileSync } from "node:fs";

const countries = JSON.parse(readFileSync("countries.json", "utf8"));
const options = countries.map(({ name, iso2 }) => ({ label: name, value: iso2 }));
console.log(options.find(o => o.value === "IN")); // { label: "India", value: "IN" }
```

## Database seed

Choose the SQL dialect that matches your database. The ZIP holds one `export.sql`.

```bash
unzip csc-postgresql-history-2026-11-24.zip -d export
psql "$DATABASE_URL" -f export/export.sql
```

## Postcode lookup

Postcodes link to a country, and optionally to a state and a city. They do not join to counties. Keep `code` as text, so a value such as `01234` keeps its zero. Use JSON or Excel when you open the file in a spreadsheet.

```js
import { readFileSync } from "node:fs";

const postcodes = JSON.parse(readFileSync("postcodes.json", "utf8"));
const match = postcodes.filter(p => p.country_code === "GB" && p.code.startsWith("SW1"));
console.log(match.length);
```

## Keep the bill small

- Select only the columns you need. Extra tiers add credits.
- Filter by country when you do not need the whole world.
- Skip sorting if your code sorts anyway.
- Use the free preview and change one option at a time.
- For newer data later, use **Renew** and expect the original credit cost again.
