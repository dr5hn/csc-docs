## Credits and pricing

<AccordionGroup>
<Accordion title="How much does an export cost?">
Dataset credits plus one format cost plus any extras. Datasets: Countries 1, States 3, Counties 3, Cities 4, Postcodes 5. Format costs are on the [Export Formats](/tools/export-tool/formats#format-costs) page. Extras are column tiers, sorting, geographic filters, translations and the flag bundle. The preview is free and shows the exact total.
</Accordion>
<Accordion title="Where are the credit packages and my balance?">
On the [Credits page](https://export.countrystatecity.in/dashboard/credits). Packages can change, so they are not copied here.
</Accordion>
<Accordion title="Do credits expire?">
No. Credits never expire.
</Accordion>
<Accordion title="Do trial credits cover a first export?">
The current 5-credit trial covers countries with core fields as JSON for 3 credits. Extra field tiers, filters and add-ons can increase the cost. Preview for free and compare the total with your balance.
</Accordion>
<Accordion title="Can I share credits with a team?">
No. Credits belong to one account.
</Accordion>
</AccordionGroup>

## Exports and downloads

<AccordionGroup>
<Accordion title="When is the file created?">
Confirming an export records it and takes the credits. The file is generated when you download it.
</Accordion>
<Accordion title="Does downloading again cost credits?">
No. Downloads never charge. If a download stops halfway, start it again from your export history.
</Accordion>
<Accordion title="How long can I download an export?">
For 30 days after you confirm it.
</Accordion>
<Accordion title="What do I get in the ZIP?">
One file per dataset, or one `workbook.xlsx` or `export.sql`, depending on the format. Exports of the current data snapshot also include `source-manifest.json` and the source notices and migration notes. See [Export Formats](/tools/export-tool/formats#whats-in-the-download).
</Accordion>
<Accordion title="Will I get an email when my export is ready?">
No. There are no ready-notification emails and no background queue. You confirm, and then you download.
</Accordion>
<Accordion title="Can I export as PDF or automate exports with an API?">
No. PDF is not offered, and the Export Tool has no automation API.
</Accordion>
</AccordionGroup>

## Data freshness

<AccordionGroup>
<Accordion title="Is the data refreshed every day?">
No daily refresh is promised. A new data snapshot is staged first and published only after it has been checked. See [`/api/status`](https://eapi.countrystatecity.in/api/status) for the snapshot that is active now.
</Accordion>
<Accordion title="Does my export change when new data is published?">
No. Each paid export keeps the snapshot it was confirmed with, and every download returns that snapshot.
</Accordion>
<Accordion title="How do I get newer data?">
Use **Renew**. It creates a new paid export for the original credit cost, uses the snapshot published at that moment, and starts a new 30 days. Your old export is not changed.
</Accordion>
<Accordion title="What happens if a new snapshot is rolled back?">
Exports you already bought keep their own snapshot. A new purchase or renewal using a dataset or field that the restored snapshot does not support is rejected before any credits are taken.
</Accordion>
</AccordionGroup>

## Data questions

<AccordionGroup>
<Accordion title="Why is a county's state_id null?">
Seven New Zealand counties have no primary state. Their state links are in the `states` column. Read that column instead.
</Accordion>
<Accordion title="Why is a city's state_id null?">
Three Western Sahara (EH) cities have no state.
</Accordion>
<Accordion title="Why did my postcode lose its leading zero?">
The `code` field is text in every export. A spreadsheet can turn it into a number when you open a CSV. Import the column as text, or use JSON or Excel.
</Accordion>
<Accordion title="Do postcodes join to counties?">
No. A postcode links to a country, and optionally to a state and a city.
</Accordion>
<Accordion title="Does every country have postcodes?">
No. Source coverage varies and worldwide coverage is not guaranteed.
</Accordion>
<Accordion title="Does the hosted API serve counties and postcodes?">
Do not assume it does. The API, the SDKs and the database packages have their own releases. See the [API docs](/api/introduction) for what the API supports.
</Accordion>
</AccordionGroup>

## Troubleshooting

<AccordionGroup>
<Accordion title="My download does not start or stops">
Start it again from your export history. If it is older than 30 days, use **Renew**. If it keeps failing, email export@countrystatecity.in with the export date and format.
</Accordion>
<Accordion title="The cost is more than I expected">
Check the extras in the preview: column tiers, sorting, geographic filters, translations and the flag bundle. Remove the ones you do not need and preview again.
</Accordion>
<Accordion title="My selection is rejected">
The selection may use a column or dataset that the active snapshot does not support. Preview it again and use the columns the app offers. Rejected selections never take credits.
</Accordion>
</AccordionGroup>

Need more help? Email export@countrystatecity.in.
