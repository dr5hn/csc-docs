## Create an account

Sign up at [export.countrystatecity.in](https://export.countrystatecity.in/) with GitHub or email. New accounts currently receive 5 trial credits. Countries with core fields as JSON costs 3 credits, with no filters or add-ons. Your balance is on the [Credits page](https://export.countrystatecity.in/dashboard/credits), together with the current credit packages. Credits never expire.

<Note>
The trial amount can change, so check your balance before you plan an export. If the preview costs more than your balance, you need to buy credits first.
</Note>

## How the price is built

Every export costs the sum of three parts.

| Part | Cost |
|:-----|:-----|
| Datasets | Countries 1, States 3, Counties 3, Cities 4, Postcodes 5 |
| One format | JSON, NDJSON, XML, YAML +2. CSV, Markdown, MongoDB +3. SQL, Excel, GeoJSON +4. PostgreSQL, SQL Server, SQLite3 +5 |
| Extras | Extra column tiers, sorting, geographic filters, translations, flag bundle |

The format cost is charged once per export, not once per dataset. The extras depend on your choices, so the preview is the only authoritative price. Always read it before you confirm. The preview is free.

<Check>
Example: Countries as JSON costs 1 + 2 = 3 credits before any extras. Countries and States as CSV costs 1 + 3 + 3 = 7 credits before any extras.
</Check>

## Create your first export

<Steps>
<Step title="Pick datasets and columns">
Select one or more datasets. Columns come from a fixed list for each dataset. See the live list at [`/api/datasets`](https://eapi.countrystatecity.in/api/datasets).
</Step>
<Step title="Add filters (optional)">
Filter by country, and sort if you need an ordered file. Both can add credits.
</Step>
<Step title="Choose a format">
See [Export Formats](/tools/export-tool/formats) for what each file looks like.
</Step>
<Step title="Preview">
The preview is free and shows a sample of the data and the exact cost.
</Step>
<Step title="Confirm">
Confirming takes the credits and records the export in your history. The file is not built yet.
</Step>
<Step title="Download">
Download from your export history. The file is generated as the download starts.
</Step>
</Steps>

## After you confirm

- You can download the export for 30 days. Downloading does not cost credits.
- If a download is interrupted, start it again from your export history. A repeat download does not charge you.
- After 30 days, use **Renew**. Renew creates a new paid export at the original credit cost. It uses the snapshot that is published at that time, and starts a new 30 days.

<Warning>
Your export keeps the data snapshot it was confirmed with. A newer snapshot never changes a file you already own. Use **Renew** when you want newer data, and note that it costs credits again.
</Warning>

## Which snapshot am I on?

Check [`/api/status`](https://eapi.countrystatecity.in/api/status). It returns the active source snapshot and the record count of each dataset.

```bash
curl -s https://eapi.countrystatecity.in/api/status
```

The `database.sourceGeneration` value is the snapshot identifier. A downloaded export includes a `source-manifest.json` that records the snapshot it came from. See [Export Formats](/tools/export-tool/formats#whats-in-the-download).
