Use the SQL Server `.sql` export with SQL Server Management Studio or `sqlcmd`. It is a script, not a `.bak` backup.

<Note>
These instructions use [v5.2.0-export.1](https://github.com/dr5hn/countries-states-cities-database/releases/tag/v5.2.0-export.1), published 3 November 2026. Its core tables contain 250 countries, 5,327 states and 156,169 city records. API data and installed package snapshots can differ. Check the [latest release](https://github.com/dr5hn/countries-states-cities-database/releases/latest) before choosing another version.
</Note>
## Download the release

Run these POSIX-shell commands in a new directory. Downloads are compressed; extract them before opening or importing.

```bash
set -eu
mkdir csc-sqlserver
cd csc-sqlserver
curl -fL 'https://github.com/dr5hn/countries-states-cities-database/releases/download/v5.2.0-export.1/sqlserver-world.sql.gz' -o world.sql.gz
gzip -d world.sql.gz
```
## Import into a new database

Create a new, empty database before importing. The example uses Windows integrated authentication (`-E`); select authentication appropriate to your installation.

```bash
set -eu
sqlcmd -S localhost -E -b -Q "CREATE DATABASE [csc_world]"
sqlcmd -S localhost -E -d csc_world -b -i world.sql
```

In SSMS, create `csc_world`, open the extracted script in a query window connected to that database, and execute it. The release creates a **schema named `world` inside the selected database**. Its table names are `world.countries`, `world.states` and `world.cities`.

## Verify the import

```sql
USE csc_world;
SELECT 'countries' AS table_name, COUNT(*) AS record_count FROM world.countries
UNION ALL SELECT 'states', COUNT(*) FROM world.states
UNION ALL SELECT 'cities', COUNT(*) FROM world.cities;
```

The pinned release lists 250 countries, 5,327 states and 156,169 city records. Inspect the imported schema when using another release.

## Query the hierarchy

```sql
SELECT TOP (10) ci.id, ci.name AS city, st.name AS state, co.name AS country
FROM world.cities AS ci
JOIN world.countries AS co ON co.id = ci.country_id
LEFT JOIN world.states AS st ON st.id = ci.state_id
WHERE co.iso2 = 'IN'
ORDER BY ci.id;
```

## Troubleshooting

- An invalid-object error can mean you omitted the `world.` schema prefix.
- Use the SQL Server export; MySQL and PostgreSQL dumps use different syntax.
- Back up existing databases before replacing data. Restore failed imports into a new database after investigating the error.

See the [SQL Server documentation](https://learn.microsoft.com/en-us/sql/sql-server/) and [sqlcmd documentation](https://learn.microsoft.com/en-us/sql/tools/sqlcmd/sqlcmd-utility) for authentication, supported versions, backups and tuning. Review the [schema reference](/database/schema) and preserve applicable data notices.
