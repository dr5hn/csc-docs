The release publishes SQLite and Parquet files. This guide uses DuckDB’s SQLite extension; DuckDB is not an additional native database export in the release.

<Note>
These instructions use [v5.2.0-export.1](https://github.com/dr5hn/countries-states-cities-database/releases/tag/v5.2.0-export.1), published 3 November 2026. Its core tables contain 250 countries, 5,327 states and 156,169 city records. API data and installed package snapshots can differ. Check the [latest release](https://github.com/dr5hn/countries-states-cities-database/releases/latest) before choosing another version.
</Note>
## Download the release

Run these POSIX-shell commands in a new directory. Downloads are compressed; extract them before opening or importing.

```bash
set -eu
mkdir csc-duckdb
cd csc-duckdb
curl -fL 'https://github.com/dr5hn/countries-states-cities-database/releases/download/v5.2.0-export.1/sqlite-world.sqlite3.gz' -o world.sqlite3.gz
gzip -d world.sqlite3.gz
```
## Install DuckDB

Use a Python version supported by the DuckDB release you install:

```bash
pip install duckdb
```

The first extension installation requires network access. Review the [DuckDB SQLite extension documentation](https://duckdb.org/docs/stable/core_extensions/sqlite) for deployment without network access.

## Query SQLite in place

```python
import duckdb

with duckdb.connect() as connection:
    connection.execute("INSTALL sqlite")
    connection.execute("LOAD sqlite")
    connection.execute("ATTACH 'world.sqlite3' AS source (TYPE SQLITE, READ_ONLY)")
    print(connection.execute("SELECT COUNT(*) FROM source.cities").fetchone()[0])
```

The pinned release has 156,169 city records.

## Create an analytical copy

Use a new destination file. This copies rows and columns; SQLite indexes, constraints and defaults are not recreated by `CREATE TABLE AS`.

```python
import duckdb
from pathlib import Path

if Path("world.duckdb").exists():
    raise FileExistsError("Choose a new destination file")

with duckdb.connect("world.duckdb") as connection:
    connection.execute("INSTALL sqlite")
    connection.execute("LOAD sqlite")
    connection.execute("ATTACH 'world.sqlite3' AS source (TYPE SQLITE, READ_ONLY)")
    for table in ("regions", "subregions", "countries", "states", "counties", "county_states", "cities", "postcodes"):
        connection.execute(f'CREATE TABLE "{table}" AS SELECT * FROM source."{table}"')
    print(connection.execute("SELECT COUNT(*) FROM cities").fetchone()[0])
```

## Query the hierarchy

Names of parent places are joined from their tables. `cities` does not store `country_name` or `state_name`; use a left join for nullable state links.

```sql
SELECT ci.id, ci.name AS city, st.name AS state, co.name AS country
FROM cities AS ci
JOIN countries AS co ON co.id = ci.country_id
LEFT JOIN states AS st ON st.id = ci.state_id
WHERE co.iso2 = 'IN'
ORDER BY ci.id
LIMIT 10;
```

## Troubleshooting

- Confirm that you selected the export for your database engine; SQL dialects are not interchangeable.
- Check the release tag and source files when counts differ. Counts from an API or a package can describe another snapshot.
- Inspect the actual table definitions before selecting columns. See the [schema reference](/database/schema).

Back up your database before replacing data or changing its schema. Keep release and source notices with distributed data; review the [ODbL licence](https://opendatacommons.org/licenses/odbl/1-0/).
DuckDB can also query a Parquet extract. A city-only file does not include the separate parent tables; retrieve matching reference files from the release source commit when you need joins. See the [DuckDB documentation](https://duckdb.org/docs/stable/) for Parquet, Arrow and analytical SQL.
