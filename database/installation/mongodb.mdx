Use MongoDB Database Tools (`mongorestore`) and `mongosh`. The published archive contains BSON dump files with metadata; it is not a JSON import file.

<Note>
These instructions use [v5.2.0-export.1](https://github.com/dr5hn/countries-states-cities-database/releases/tag/v5.2.0-export.1), published 3 November 2026. Its core tables contain 250 countries, 5,327 states and 156,169 city records. API data and installed package snapshots can differ. Check the [latest release](https://github.com/dr5hn/countries-states-cities-database/releases/latest) before choosing another version.
</Note>
## Download and extract

```bash
set -eu
mkdir csc-mongodb
cd csc-mongodb
curl -fL 'https://github.com/dr5hn/countries-states-cities-database/releases/download/v5.2.0-export.1/mongodb-world-mongodb-dump.tar.gz' -o world-mongodb-dump.tar.gz
tar -xzf world-mongodb-dump.tar.gz
```

The dump is under `mongodb-dump/world/`. Inspect the files before restoring:

```bash
find mongodb-dump/world -maxdepth 1 -type f
```

## Restore into a new database

Choose an empty destination such as `csc_world`. Adjust the URI and authentication options for your server. Confirm the destination has no collections before restoring.

```bash
set -eu
mongosh 'mongodb://127.0.0.1:27017/csc_world' --quiet --eval 'if (db.getCollectionNames().length) throw new Error("Choose an empty destination database");'
mongorestore --uri='mongodb://127.0.0.1:27017' --stopOnError --nsInclude='world.*' --nsFrom='world.*' --nsTo='csc_world.*' mongodb-dump
```

The namespace options restore the source `world` collections into `csc_world`. Preserve existing databases and investigate any restore error before retrying. For a remote server, use authenticated access and the connection settings required by that server.

## Verify the restore

```bash
mongosh 'mongodb://127.0.0.1:27017/csc_world' --quiet --eval 'printjson({countries: db.countries.countDocuments(), states: db.states.countDocuments(), cities: db.cities.countDocuments()})'
```

The pinned release lists 250 countries, 5,327 states and 156,169 city records. Inspect an individual document and its fields before writing application queries:

```javascript
db.cities.findOne({ name: "Mumbai", country_code: "IN" })
```

## Troubleshooting

- BSON dumps are restored with `mongorestore`. MongoDB Compass JSON import and `mongoimport` require a different file format.
- Use `mongosh` for shell commands; the older `mongo` shell is not required.
- Check the namespace mapping if collections appear under an unexpected database name.
- Back up existing data before replacement. Review the release and its notices before distribution.

See the [mongorestore reference](https://www.mongodb.com/docs/database-tools/mongorestore/) and [mongosh documentation](https://www.mongodb.com/docs/mongodb-shell/) for version compatibility, authentication and backups.
